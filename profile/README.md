# AR-IMMS

**AR-assisted Infrastructure Monitoring and Maintenance System**

AR-IMMS is a proof of concept for monitoring a small data-center-like environment and helping technicians investigate and handle infrastructure issues.

The project explores:

- Collecting and viewing infrastructure telemetry.
- Linking alerts and incidents to infrastructure assets.
- Helping technicians identify assets and view maintenance context with QR and augmented reality.
- Providing AI-assisted investigation hints and maintenance checklists.

This organization contains the project’s application and telemetry-agent repositories.
